Nous avons développé une application Android de gestion de pizzas qui permet aux utilisateurs de :

Découvrir une liste de pizzas avec leurs caractéristiques
Visualiser les détails complets de chaque pizza
Naviguer de façon fluide entre les écrans

# Architecture Réalisée

L'application suit une architecture propre et organisée en couches :
Couche DAO (Interface IDao) : Définit les opérations CRUD standard
Couche Service (ProduitService) : Implémente la logique métier et les données
Couche Adapter (PizzaAdapter) : Gère l'affichage de la liste avec RecyclerView
Couche UI (Activities) : Interface utilisateur (Splash, Liste, Détail)
